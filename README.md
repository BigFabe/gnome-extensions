# GNOME Extensions

Meine GNOME-Shell-Erweiterungen in einem gemeinsamen Repository.

## Extensions

| Verzeichnis | Extension | Beschreibung |
| --- | --- | --- |
| [`gnome-pomodoro-ext`](gnome-pomodoro-ext/) | Pomodoro Timer | Konfigurierbarer Fokus-Timer mit Aufgabenliste und Panel-Anzeige |
| [`gnome-macos-switcher-shift`](gnome-macos-switcher-shift/) | macOS Switcher Shift | macOS-artige Vorwaerts- und Rueckwaertsnavigation im GNOME-App-Switcher |
| [`gnome-stt-ext`](gnome-stt-ext/) | Push-to-Talk STT | Lokale Spracheingabe unter Wayland mit Parakeet |

Installation, Voraussetzungen und Entwicklungshinweise stehen in der README der jeweiligen Extension.
